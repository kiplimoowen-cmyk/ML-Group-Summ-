# ML-Group-Summ-

This project explores several machine learning techniques for **unsupervised learning, similarity-based modeling, anomaly detection, and recommendation systems**.

## Topics Covered

* **K-Means Clustering** – customer segmentation and grouping based on similarity
* **Gaussian Mixture Models (GMM)** – probabilistic clustering and anomaly detection
* **Principal Component Analysis (PCA)** – dimensionality reduction and feature transformation
* **k-Nearest Neighbors (k-NN)** – similarity-based classification and prediction
* **Distance Metrics** – Euclidean, Manhattan, and Chebyshev distance
* **Recommendation Systems** – content-based, collaborative, and hybrid approaches
* **Model Evaluation** – clustering and recommendation-system evaluation techniques

## Key Skills

`Python` · `Pandas` · `NumPy` · `Scikit-learn` · `Surprise` · `Matplotlib` · `Seaborn`

## Objective

The project demonstrates how different machine learning approaches can be applied to **identify patterns, segment data, measure similarity, reduce dimensionality, detect anomalies, and generate personalized recommendations**.
